# Telegram-бот: Менеджер паролей

## Авторы (Группа 6310)
* **Воронов Александр** — проектирование структуры базы данных SQLite, интеграция функций шифрования паролей (Fernet), защита от SQL-инъекций и теоретический анализ уязвимостей серверного хранения данных.
* **Глебов Семен** — разработка асинхронного ядра Telegram-бота на aiogram, создание интерактивного интерфейса, написание обработчиков команд (handlers) и интеграция программных модулей.

## Стек технологий
* Язык программирования: Python 3
* Фреймворк бота: aiogram 3 (Асинхронный)
* База данных: СУБД SQLite3
* Шифрование данных: Модуль cryptography (алгоритм Fernet)
* Безопасная генерация: Модуль secrets

## Описание текущей архитектуры
Приложение генерирует пароли через криптографически стойкий модуль `secrets`. Перед сохранением в базу данных пароль шифруется симметричным алгоритмом Fernet (AES). База данных представляет собой одну таблицу в СУБД SQLite.
